## About

Bangladesh's hackathon scene produces some genuinely great problem sets every year — and almost all of them disappear the moment the event ends, scattered across private Drives, expired Facebook links, and forgotten Discord servers. `bd-hackathon-archive` exists to fix that: one open, organized, permanent home for every problem statement, built and maintained by the community that wrote and solved them.

Whether you're prepping for your first hackathon, building a practice set, or just curious what problems your favorite university has run, it's all here — searchable, versioned, and free.

## How to Contribute

This archive only exists because people share what they have. Got a problem set sitting in your downloads folder? Drop it in. Full walkthrough — file naming, folder structure, PR checklist — is in [CONTRIBUTING.md](CONTRIBUTING.md).
